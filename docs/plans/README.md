# Execution Plans

Step-by-step checklists for executing the roadmap phases.

## Purpose

These files capture the concrete tasks, open decisions, and progress for each
development phase, so any future session can resume without re-planning.

## How to use

1. At the start of a session, open the active plan below.
2. Work through the unchecked steps.
3. Mark steps as done (`[x]`) as they are completed.
4. Record decisions and important notes in the plan file.

## Rules

* Plans are execution aids, not sources of truth. Scope and architecture are
  defined in `ROADMAP.md`, `ARCHITECTURE.md`, `DATA_MODEL.md`, and `DESIGN.md`.
* When a plan and a source-of-truth document disagree, the source-of-truth
  document wins.
* Completed plans stay in the folder for reference.
